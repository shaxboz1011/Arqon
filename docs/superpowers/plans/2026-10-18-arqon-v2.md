# Arqon v2 Implementation Plan: system mode and pro features

**Goal:** make system-wide steering real (every app, not only the built-in downloader) and add the features that make Arqon pleasant to live with.

**Architecture:** all decision and packet logic lives in `Arqon.Core` and is unit-tested without a driver. The only untestable part (WinDivert P/Invoke) is a thin wrapper that fails open.

**Spec:** `docs/superpowers/specs/2026-10-18-arqon-design.md`, `docs/steering.md`.

## Global Constraints

- Core stays UI-free; `TreatWarningsAsErrors` stays on.
- System mode must fail open: any error, a closed handle or process exit returns Windows to normal routing.
- IPv4 TCP/UDP only. Loopback, private ranges, multicast, broadcast and IPv6 pass through untouched.
- Arqon's own download traffic is never re-steered.
- No third-party NuGet packages.

## Review Focus

- A fragmented, truncated or malformed packet must pass through unchanged and never throw.
- A steered link that never answers must be taken out of rotation instead of black-holing connections.
- Two packets of one new flow must get the same link (already covered by the coordinator lock).
- Link plugged in or removed while steering is on.
- Latency guard must never throttle to zero and must release when the network calms down.

## Tasks

1. `PacketView` + `InternetChecksum`: parse IPv4 TCP/UDP, rewrite addresses, recompute checksums.
2. `NatSteeringEngine`: outbound decision + source rewrite, inbound restore, private/own-process bypass, unanswered-link quarantine.
3. `WindowsProcessResolver`: local port to process id and exe name (`GetExtendedTcpTable` / `GetExtendedUdpTable`).
4. `WinDivertNative` + `WinDivertSteerer` + `SteeringService`: driver wrapper, link-change reconfigure, availability check.
5. `SpeedGovernor` + `LatencyGuard`: runtime download cap that backs off when game ping rises.
6. `GameWatcher`: detects running catalogue games, switches game mode on and off.
7. `UsageTracker`: per-link daily byte totals, persisted.
8. App: Usage page with stacked bar chart, system-mode toggle and live steering status, tray icon and notifications, clipboard link banner.
9. Docs, README, review, fixes.
